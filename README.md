🧹 AI Data Cleaning Assistant

What I Built:
A web app that automatically cleans messy Excel/CSV files using AI. Upload any dirty file - AI detects issues and cleans it in seconds.

Key Features:
- Remove duplicate rows
- Fill missing values automatically
- Remove extra spaces from text
- Standardize text to lowercase
- AI detects what needs cleaning
- Download cleaned file instantly

Why This Matters:
Data cleaning is 80% of a data scientist's job. This tool automates that work.

Tools:
Python, Streamlit, Google Gemini AI, Pandas

Note: Code assisted by AI, fully tested and deployed by me.
